# Wedding Visuals and Materials · 婚礼视觉与物料策划

[中文](#中文) | [English](#english)

## 中文

一份面向 AI Agent 的婚礼视觉与物料策划 Skill。它帮助新人确定主视觉、选择和搭配物料、准备素材，并协调可用创意工具完成设计。

### 使用

1. 对支持 Skill 文件的 Agent，按该平台的说明导入包含 [SKILL.md](SKILL.md) 的文件夹。
2. 不支持导入 Skill 的工具，可将 [SKILL.md](SKILL.md) 的内容粘贴到对话或自定义指令中，再描述需求。
3. Agent 应根据你使用或指定的语言交流。图片生成、可编辑文件及自动加载能力取决于平台和可用工具；各平台兼容性尚未逐一验证。

示例：

> 帮我们设计海边婚礼的电子请柬、迎宾牌和桌卡。我们喜欢温暖、有艺术感的风格，请先问我需要确认的信息。

欢迎通过 Issue 或 Pull Request 分享改进建议和使用经验。使用本项目即受 [MIT 许可证](LICENSE)条款约束。

## English

A wedding visual and materials skill for AI agents. It helps couples establish a visual direction, select coordinated materials, prepare assets and use available creative tools.

### Usage

1. For an agent that supports skill files, import the folder containing [SKILL.md](SKILL.md) according to that platform’s instructions.
2. Otherwise, paste [SKILL.md](SKILL.md) into a conversation or custom instructions and describe your brief.
3. The agent should respond in your language or the language you request. Automatic loading, image generation and editable file support depend on the platform and available tools; individual platforms have not yet been tested.

Example:

> Help us design a digital invitation, welcome sign and place cards for a beach wedding. We like a warm, artistic style. Start by asking what you need to know.
